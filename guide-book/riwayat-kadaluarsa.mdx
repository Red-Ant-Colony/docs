# <a id="_heading=h.f839vw6pvrw5"></a>1\. Riwayat Kedaluwarsa

Fitur __Riwayat Produk Kadaluarsa __pada aplikasi Zycas ini__ __menyediakan catatan lengkap tentang semua produk yang telah melewati tanggal kadaluarsanya\. Halaman ini berfungsi sebagai arsip penting untuk membantu Anda menganalisis produk\-produk yang tidak laku dan mengevaluasi manajemen stok\.

## <a id="_heading=h.8x8f5an5bn4k"></a>1\.1\. Cara Akses List Riwayat Kadaluarsa 

__Berikut cara mengakses halaman list riwayat kadaluarsa : __

1. Tekan ikon tiga garis di pojok kiri atas

![](/guide-book/images/riwayat-kadaluarsa-12.png)

1. Setelah menekan ikon hamburger, maka akan menampilkan sidebar list menu

![](/guide-book/images/riwayat-kadaluarsa-13.png)

1. Tekan menu Produk pada list menu

![](/guide-book/images/riwayat-kadaluarsa-14.png)

1. Setelah tekan menu Produk, maka akan menampilkan list sub menu Produk

![](/guide-book/images/riwayat-kadaluarsa-15.png)

1. Lalu tekan menu Riwayat Produk Kadaluarsa pada list sub menu Produk

![](/guide-book/images/riwayat-kadaluarsa-16.png)

1. Setelah menekan menu Riwayat Produk Kadaluarsa maka akan menampilkan halaman list riwayat kadaluarsa\. 

![](/guide-book/images/riwayat-kadaluarsa-17.png)

## <a id="_heading=h.lu4yj7a49x1e"></a>1\.2\. Cara Hapus Riwayat Kadaluarsa 

__Berikut cara mengakses halaman hapus riwayat kadaluarsa : __

1. Tekan ikon keranjang sampah pada salah satu list produk kadaluarsa di halaman list riwayat kadaluarsa

![](/guide-book/images/riwayat-kadaluarsa-18.png)

1. Setelah menekan tombol, maka akan menampilkan halaman pop up konfirmasi hapus riwayat kadaluarsa

![](/guide-book/images/riwayat-kadaluarsa-19.png)

1. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk hapus riwayat kadaluarsa

![](/guide-book/images/riwayat-kadaluarsa-20.png)

1. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan hapus riwayat kadaluarsa 

![](/guide-book/images/riwayat-kadaluarsa-21.png)

1. Jika Anda memilih tombol __Ya, Saya Yakin__, maka data riwayat kadaluarsa akan berhasil terhapus dan secara otomatis diperbarui pada sistem\.

![](/guide-book/images/riwayat-kadaluarsa-22.png)

## 1\.5\. Cara Reset PIN User

__Berikut cara reset PIN:__

1. Tekan tombol “Reset PIN” di halaman list user untuk memulai proses reset PIN user

![](/guide-book/images/user-85.png)

1. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi reset pin user

![](/guide-book/images/user-86.png)

1. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk melanjutkan reset pin user

![](/guide-book/images/user-87.png)

1. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan reset pin user

![](/guide-book/images/user-88.png)

1. Setelah menekan tombol “Ya, Saya Yakin”,  maka akan menampilkan halaman list user serta notifikasi “PIN  Berhasil Di Reset”

![](/guide-book/images/user-89.png)

__Deskripsi \(Penjelasan dalam Bahasa Indonesia\)__

Zycas Mobile

Aplikasi mobile yang digunakan untuk mengelola operasional bisnis seperti transaksi, pengguna, dan pengaturan sistem\.

Pengguna \(User\)

Orang yang menggunakan aplikasi Zycas Mobile dengan hak akses tertentu\.

Owner

Pengguna dengan hak akses penuh untuk mengelola seluruh menu, data, dan pengaturan sistem Zycas\.

Karyawan

Pengguna dengan hak akses terbatas sesuai izin yang diberikan oleh owner\.

Hak Akses

Izin yang menentukan menu dan fitur apa saja yang dapat diakses oleh pengguna\.

Modul User

Modul manajemen pengguna untuk mengatur data user, hak akses, dan keamanan akun dalam Zycas Mobile\.

User List

Halaman yang menampilkan daftar seluruh pengguna yang terdaftar dalam sistem\.

Tambah User

Fitur atau tombol untuk menambahkan pengguna baru ke dalam sistem\.

Edit User

Fitur untuk mengubah data pengguna yang telah terdaftar\.

Detail User

Fitur untuk melihat informasi lengkap dan rinci mengenai seorang pengguna\.

Status User

Penanda kondisi akun pengguna, aktif atau non\-aktif\.

Cari User

Fitur pencarian untuk menemukan user tertentu dalam daftar user\.

Filter Status User

Fitur untuk menyaring daftar user berdasarkan status aktif atau non\-aktif\.

Reset Password

Fitur untuk mengganti kata sandi pengguna demi keamanan atau karena lupa password\.

Reset PIN

Fitur untuk mengatur ulang PIN pengguna agar dapat kembali mengakses sistem\.

Unggah Foto

Fitur untuk mengunggah foto profil pengguna\.

Nama User

Informasi identitas nama pengguna\.

Jabatan

Peran atau posisi pengguna dalam organisasi yang memengaruhi hak akses sistem\.

Email

Alamat email pengguna yang digunakan sebagai informasi kontak atau akun login\.

No\. WhatsApp

Nomor WhatsApp pengguna sebagai informasi kontak\.

No\. KTP

Nomor identitas pengguna yang digunakan untuk keperluan data administrasi\.

Password

Kata sandi yang digunakan pengguna untuk masuk ke sistem\.

Verifikasi Password

Kolom konfirmasi untuk memastikan password yang dimasukkan sudah benar\.

PIN

Kode keamanan tambahan yang digunakan pengguna untuk mengakses sistem\.

Permission

Pengaturan izin akses pengguna terhadap menu dan fitur tertentu dalam Zycas Mobile\.

Reset Permission

Fitur untuk mengembalikan pengaturan permission ke kondisi sebelumnya\.

Reset Identitas User

Fitur untuk mengembalikan data identitas user ke sebelum dilakukan perubahan\.

Sidebar Menu

Notifikasi

Dashboard

Halaman utama sistem yang menampilkan ringkasan fitur dan menu sesuai permission user\.

Administrator

Pengguna yang memiliki kewenangan untuk mengelola data user, termasuk reset password dan PIN\.

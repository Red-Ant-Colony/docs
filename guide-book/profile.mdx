# 1. Profile

Fitur profil pada aplikasi Zycas berguna untuk mengelola informasi akun. Pada halaman ini, pengguna dapat melihat informasi user, informasi permission, mengubah password, ubah pin, request hapus akun, dan logout.

![](/guide-book/images/profile-8.png)

![](/guide-book/images/profile-9.png)![](/guide-book/images/profile-10.png)


| No | Simbol | Keterangan |
| --- | --- | --- |
| 1 | Ubah password | Tombol untuk mengubah password |
| 2 | Ubah pin | Tombol untuk mengubah pin |

## 1.1. Cara Mengakses Menu Profile

__Berikut cara mengakses menu profil:__

1. Tekan ikon tiga garis di pojok kiri atas

![](/guide-book/images/profile-11.png)

2. Setelah menekan ikon, maka akan menampilkan sidebar list menu

![](/guide-book/images/profile-12.png)

3. Tekan menu Profil pada list menu 

![](/guide-book/images/profile-13.png)

4. Setelah menekan menu profil maka akan menampilkan halaman profil

## 1.2. Cara Mengubah Password

Menu __Ubah Password __adalah menu yang berisi form untuk mengubah password lama ke password baru. Untuk mengakses halaman ini adalah dengan klik Menu __ubah password__ di halaman profil

![](/guide-book/images/profile-14.png)

![](/guide-book/images/profile-15.png)![](/guide-book/images/profile-16.png)

![](/guide-book/images/profile-17.png)


| No | Simbol | Keterangan |
| --- | --- | --- |
| 1 | Password Lama | Kolom untuk mengisi password lama |
| 2 | Password Baru | Kolom untuk mengisi password baru |
| 3 | Verifikasi Password Baru | Kolom untuk mengisi verifikasi password baru |

__Berikut merupakan langkah-langkah untuk mengubah password : __

1. Masukkan password lama ke dalam kolom password lama 

![](/guide-book/images/profile-18.png)

2. Masukkan password baru anda ke dalam kolom password baru 

![](/guide-book/images/profile-19.png)

3. Masukkan ulang password anda di kolom verifikasi password baru

![](/guide-book/images/profile-20.png)

4. Setelah selesai mengisi data ubah password, kemudian tekan tombol “Ubah Password”

![](/guide-book/images/profile-21.png)

5. Setelah menekan tombol, maka akan menampilkan halaman konfirmasi ubah password

![](/guide-book/images/profile-22.png)

6. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk melanjutkan ubah password

![](/guide-book/images/profile-23.png)

7. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan ubah password

![](/guide-book/images/profile-24.png)

8. Setelah menekan tombol “Ya, Saya Yakin”,  maka akan menampilkan halaman profil serta notifikasi “Perubahan Password Berhasil Disimpan”

![](/guide-book/images/profile-25.png)

## 1.4. Cara Request Hapus Akun

Menu __Request Hapus Akun __adalah menu yang berisi konfirmasi untuk mengajukan hapus akun kepada admin. Untuk mengakses halaman ini adalah dengan klik Menu __Request Hapus Akun __di sidebar menu

![](/guide-book/images/profile-38.png)

__Berikut merupakan langkah-langkah untuk request hapus akun : __

1. Tekan ikon tiga garis di pojok kiri atas

![](/guide-book/images/profile-39.png)

2. Setelah menekan ikon, maka akan menampilkan sidebar list menu

![](/guide-book/images/profile-40.png)

3. Tekan menu Request Hapus Akun pada list menu 

![](/guide-book/images/profile-41.png)

4. Setelah menekan menu profil maka akan menampilkan pop up konfirmasi request hapus akun

![](/guide-book/images/profile-42.png)

5. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk melanjutkan request hapus akun

![](/guide-book/images/profile-43.png)

6. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan request hapus akun

![](/guide-book/images/profile-44.png)

7. Setelah menekan tombol “Ya, Saya Yakin”,  maka akan menampilkan pesan notifikasi “Penghapusan akun berhasil diajukan\! Silahkan tunggu persetujuan dari Admin”

![](/guide-book/images/profile-45.png)

8. Anda akan diarahkan ke halaman halaman privacy policy untuk penghapusan akun

![](/guide-book/images/profile-46.png)

9. Tekan tulisan “data subject access request” untuk diarahkan ke halaman form request hapus akun

![](/guide-book/images/profile-47.png)

10. Isi data-data pada form request hapus akun dengan lengkap

![](/guide-book/images/profile-48.png)

11. Setelah selesai mengisi form, tekan tombol “Submit”

![](/guide-book/images/profile-49.png)

<Note>
Fitur Request Hapus Akun hanya dapat dilakukan oleh user owner

## 1.5. Logout

Menu __logout  __adalah menu yang berisi konfirmasi untuk keluar akun Zycas. Untuk mengakses halaman ini adalah dengan klik Menu __Logout __di halaman di sidebar menu

![](/guide-book/images/profile-50.png)

__Berikut cara logout aplikasi:__

1. Tekan ikon tiga garis di pojok kiri atas

![](/guide-book/images/profile-51.png)

2. Setelah menekan ikon, maka akan menampilkan sidebar list menu

![](/guide-book/images/profile-52.png)

3. Tekan menu Logout pada list menu 

![](/guide-book/images/profile-53.png)

4. Setelah menekan tombol, maka akan menampilkan pop up konfirmasi logout

![](/guide-book/images/profile-54.png)

5. Tekan tombol “Ya, Saya Yakin” di halaman konfirmasi untuk melanjutkan logout

![](/guide-book/images/profile-55.png)

6. Tekan tombol “Tidak” di halaman konfirmasi untuk membatalkan logout

![](/guide-book/images/profile-56.png)

7. Setelah menekan tombol “Ya, Saya Yakin”,  maka akan menampilkan halaman login Zycas serta notifikasi “Berhasil keluar dari Zycas\! Silahkan Masuk kembali”

__Istilah__

__Deskripsi (Penjelasan dalam Bahasa Indonesia)__

Zycas Mobile

Aplikasi mobile untuk mengelola transaksi, stok, dan operasional bisnis ritel.

Pengguna (User)

Individu yang menggunakan aplikasi Zycas dengan hak akses tertentu.

Owner

Pengguna dengan hak akses penuh terhadap seluruh menu dan fitur aplikasi Zycas.

Karyawan

Pengguna dengan hak akses terbatas sesuai izin yang diberikan oleh owner.

Hak Akses

Pengaturan izin yang menentukan fitur dan menu yang dapat diakses oleh pengguna.

Profile

Menu pada Zycas Mobile yang digunakan untuk mengelola informasi akun dan keamanan pengguna.

Modul Profile

Pusat manajemen akun personal untuk mengatur identitas, keamanan, dan sesi login pengguna.

Informasi User

Data identitas pengguna yang ditampilkan pada halaman profil.

Informasi Permission

Informasi mengenai hak akses atau izin yang dimiliki oleh pengguna.

Ubah Password

Fitur untuk mengganti password lama dengan password baru.

Password Lama

Password yang sedang digunakan dan harus diisi sebagai verifikasi sebelum perubahan.

Password Baru

Password baru yang akan digunakan setelah proses perubahan berhasil.

Verifikasi Password Baru

Kolom konfirmasi untuk memastikan password baru diinput dengan benar.

Ubah PIN

Fitur untuk mengganti PIN lama dengan PIN baru pada akun pengguna.

PIN Lama

PIN yang sedang aktif dan digunakan sebagai verifikasi perubahan PIN.

PIN Baru

PIN baru yang akan digunakan setelah perubahan disimpan.

Verifikasi PIN Baru

Kolom konfirmasi untuk memastikan PIN baru diinput dengan benar.

Request Hapus Akun

Fitur untuk mengajukan permintaan penghapusan akun kepada admin.

Pop Up Konfirmasi

Jendela dialog yang meminta persetujuan pengguna sebelum melanjutkan suatu aksi.

Admin

Pihak yang memiliki wewenang untuk menyetujui atau memproses permintaan penghapusan akun.

Privacy Policy

Halaman kebijakan privasi yang menjelaskan pengelolaan data pengguna.

Data Subject Access Request

Tautan atau fitur untuk mengajukan permintaan terkait pengelolaan atau penghapusan data akun.

Form Request Hapus Akun

Formulir yang harus diisi pengguna untuk mengajukan penghapusan akun secara resmi.

Logout

Proses keluar dari akun Zycas dan mengakhiri sesi pengguna.

Halaman Login

Halaman awal aplikasi Zycas yang digunakan untuk masuk ke akun pengguna.

Ikon Hamburger

Ikon tiga garis yang digunakan untuk membuka sidebar menu.

Sidebar Menu

Panel navigasi samping yang menampilkan daftar menu aplikasi.

Notifikasi

Pesan sistem yang menampilkan status keberhasilan atau pembatalan suatu aksi.

Konfirmasi Aksi

Proses persetujuan pengguna sebelum sistem menjalankan perintah tertentu.

Sesi Login

Kondisi saat pengguna sedang masuk dan aktif menggunakan aplikasi.
